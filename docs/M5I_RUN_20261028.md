`6ad290…`, `5ed743…`, `5ed743…`; the responses remain archived in
`data/m5i/run-20261028/probe.sqlite3`. We did not assume these were interchangeable.
Initial unpinned workers safely used separate namespaces, but alternating between
them divides progress and makes a simple elapsed-time estimate unreliable.

The ongoing run now requires the exact previously validated identity
`6ad290cf06017f5a5aba88e4f878e7b3320b73c8ac1d8018d376aab00d64cb16`.
Each worker tries at most three probes inside its existing HTTP budget. If none
matches, inference reports `PINNED_MODEL_IDENTITY_MISMATCH` without changing the
active namespace; retrieval and collection remain independent. Other-identity
vectors are preserved but never merged or relabeled. An actual model upgrade
therefore requires a deliberate new namespace/run configuration.
